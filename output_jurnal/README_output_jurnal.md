# Output untuk Artikel Jurnal

Folder ini berisi tabel CSV, grafik PNG beresolusi 300 dpi, dua peta HTML interaktif, daftar tabel/visualisasi, dan ringkasan temuan. Tabel 1-16 dirujuk pada `Daftar_tabel_jurnal.csv`; Gambar 1-10 pada `Daftar_visualisasi_jurnal.csv`.

Jumlah kota adalah Id Proyek unik per tahun. Jumlah lintas sektor atau kecamatan dapat menghitung proyek lebih dari sekali. Tabel pertumbuhan membedakan YoY dan perubahan kumulatif 2021-2025; LQ memuat semua 31 kecamatan x 83 kode KBLI dan mengidentifikasi kombinasi tanpa kegiatan sebagai LQ 0 jika sektornya aktif di kota. CAGR memakai empat interval tahunan, rata-rata LQ berbobot sama antar-kecamatan dan antar-tahun, dan analisis gabungan tidak memakai DLQ.

Lihat `Validasi_akhir.csv` dan `Ringkasan_temuan_utama.md` untuk asumsi, validasi, serta pemeriksaan manual yang masih diperlukan.
